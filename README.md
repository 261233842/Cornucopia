# Cornucopia
###### Compatible with AppleSkin mod from version 2.1.1 version!

## Add Cornucopia

Cornucopia is a new food storage item that allows players to quickly and easily access its food resources. Now you can get a Cornucopia not only by joining a world, but also by using a goat horn item filled with food.

### The Way To Get Cornucopia
- **New World Rewards**: When you join a new game world, the system will automatically give you a Cornucopia.
- **Goat Horn Conversion**: By right-clicking a goat horn filled with food, you can convert it into a cornucopia horn.

### Shortcut Key
- **Shift + Q**: Discard all food in Cornucopia.

## Feeding Mechanism

Based on the player's health and hunger, choose the following foods:

- **Full Hunger Value**: When the player's hunger level is full, choose the food that can be eaten at full hunger level.
- **10 < Health**: Prioritize foods that maximize hunger value. In the case of the same overflow or insufficient hunger value, preference is given to the food that returns the most hunger value.
- **6 < Health <= 10**: If there are **golden carrots**, preference will be given to **golden carrots** for consumption.
- **Health <= 6**: If there are **(enchanted) golden apples**, preference will be given to **(enchanted) golden apples** for consumption *(the preference between the two depends on the order in which they are placed). The one on the left of Cornucopia is preferred)*

# 丰饶之角
###### 从2.1.1版本开始，兼容苹果皮模组!

## 概述

丰饶角是一个存储食物的新物品，它允许玩家快捷并方便地访问其中的食物资源。

### 获取丰饶角的方法
- **新世界奖励**：当您加入一个新的游戏世界时，系统将自动赠送一个丰饶角。
- **山羊角转换**：通过右键使用装满食物的山羊角，可以将其转换为丰饶角。

### 快捷键
- **Shift + Q**：将丰饶角中的所有食物全部丢弃。

## 进食机制

根据玩家的生命值和饥饿值，按照下列规则选择食物：

- **满饥饿值**：当玩家的饥饿值已满时，选择可以在满饥饿值的情况下被食用的食物。
- **10 < 生命值**：优先选择那些可以使饥饿值尽可能达到满值的食物。在溢出或不足的饥饿值相同的情况下，优先选择回复饥饿值最多的食物。
- **6 < 生命值 <= 10**：如果有**金胡萝卜**，将优先选择**金胡萝卜**进行食用。
- **生命值 <= 6**：如果有 **（附魔）金苹果**，将优先选择 **（附魔）金苹果** 进行食用 *（两者之间的选择优先级，取决于放入的顺序。丰饶角中靠左的优先吃）*
